# hxyfront-62009 地毯修复纹样标记放行台

给手工地毯修复工作室使用的纹样标记放行台前端：在纹样图上标出破损框，登记框坐标、补线色号与施工前照片，
通过校验后放行进入施工工序；全部数据仅保存在浏览器 localStorage，重开页面自动恢复。

## 放行规则（任一不满足，整张档案不能放行）

- 至少标出一个破损框；
- 同毯破损框不得相交；
- 每个破损框的补线色号必须在材料色卡内，且色卡余量充足（每框占用 1 份）；
- 每个破损框必须有施工前照片。

校验不通过时，原放行队列、色卡余量与工序进度均不变化。

## 放行后变更

- 已放行档案中移动任一破损框（拖动或改坐标/尺寸）：该框及后续工序全部失效，整张档案退回复核；
  已占用色卡余量随之释放，档案重新回到放行队列。
- 施工前照片一经放行即只读；施工后照片上传后同样只读留档。
- 重新放行后失效工序恢复为待施工，按「清创除尘 → 配色试线 → 补线织补 → 平整收边」顺序推进。

## 同步视图

纹样图标记、材料色卡余量统计、工序进度条与产地筛选实时同步。
